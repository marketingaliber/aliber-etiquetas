# Aliber Etiquetas

Etiquetas de gôndola para clientes do PDV+, impressas na Elgin i8 / i9 (bobina 80 mm,
com corte automático). Puxa nome e preço do PDV+ (somente leitura) ou de produtos avulsos.

## No cliente
1. Instale com `AliberEtiquetas-Instalador-X.Y.Z.exe` (atalho na área de trabalho).
2. Configurações > Impressora: escolha a Elgin (USB, com o driver da Elgin) ou informe o IP.
3. Configurações > PDV+: confira a pasta (padrão `C:\PDV+`) e o nome da loja do rodapé.
4. Em Etiquetas: marque os produtos, escolha o modelo e clique em Imprimir selecionadas.
   O filtro "Preço mudou" mostra o que precisa de etiqueta nova desde a última impressão.
